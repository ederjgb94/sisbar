# SISBAR - Sistema de Gestión para Bares

SISBAR es una aplicación de Flutter diseñada para modernizar y optimizar la gestión de bares, restaurantes y establecimientos similares.

## 🚀 Características

- **Gestión de inventario**: Control de stock de bebidas e insumos
- **Sistema de órdenes**: Toma de pedidos digital y seguimiento en tiempo real
- **Punto de venta**: Procesamiento de pagos rápido y eficiente
- **Reportes analíticos**: Estadísticas de ventas, productos populares y horas pico
- **Gestión de personal**: Control de horarios y rendimiento de empleados
- **Fidelización de clientes**: Sistema de recompensas y promociones personalizadas

## 🛠️ Instalación

1. **Requisitos previos**
   - Flutter (versión 3.0 o superior)
   - Dart (versión 2.17 o superior)
   - Firebase account (para backend y autenticación)
   - Android Studio / VS Code

2. **Clonar el repositorio**
   ```bash
   git clone https://github.com/usuario/sisbar.git
   cd sisbar
   ```

3. **Instalar dependencias**
   ```bash
   flutter pub get
   ```

4. **Configurar**
   - Permisos de camara
   - Permisos de internet
   - Permisos de almacenamiento

5. **Ejecutar la aplicación**
   ```bash
   flutter run
   ```

## 📱 Uso

- **Inicio de sesión**: Accede con tus credenciales de administrador o empleado
- **Dashboard principal**: Visualiza las métricas importantes del día
- **Gestión de mesas**: Asigna mesas, visualiza su estado actual y duración de ocupación
- **Catálogo de productos**: Administra tu menú de bebidas y alimentos
- **Historial de transacciones**: Revisa ventas pasadas y genera informes

## 🔧 Tecnologías utilizadas

- **Flutter**: Framework de UI
- **Firebase**: Backend y autenticación
- **Provider**: Gestión de estado
- **Hive**: Almacenamiento local
- **Charts**: Visualización de datos
